DisplayXRAn open runtime for 3D displays

Spatial displays now ship from many vendors, but each app still has to integrate each panel by hand. DisplayXR is a vendor-neutral, OpenXR-based runtime: write an app once and it runs in 3D on any supported display, on Windows, macOS and Android. Leia is a founding member and the first display vendor. The project is independent and open to every display maker.

  • displayxr-runtime

    The OpenXR runtime for tracked 3D displays.

  • displayxr-browser

    Chromium that renders the web normally and adds inline 3D on DisplayXR hardware.

  • displayxr-web

    The inline-3D web SDK and samples. This page is built with it.

  • displayxr-unity and Unreal

    Engine plugins for 3D displays.

  • displayxr-extensions

    OpenXR extension specs and headers for 3D displays.

  • displayxr-vendor-template

    A starter kit for adding a new display.

LeiaGlasses-free 3D, from the lab to products

Leia grew out of my research at HP Labs on diffractive light-field backlights, published in Nature:

Fattal et al., A multi-directional backlight for a wide-angle, glasses-free three-dimensional display. Nature 495, 348–351 (2013).

Today Leia builds switchable 3D displays with eye tracking and AI-based 2D-to-3D conversion for phones, tablets, laptops and monitors. More at leiainc.com.
